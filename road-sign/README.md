# 京滋ロードサイン・ネットワーク

BRIDGE CYCLE株式会社の屋外看板マッチングLP（広告主向け・看板会社向け）。

- index.html：広告主向け
- partner.html：看板会社向け
- config.js：フォーム送信先（FormSubmit → info@bridgecycleco.com）。Formspreeに切り替える場合は formEndpoint を変更
- app.js：媒体の広告料試算（紹介料率は表示しない）、フォーム送信、計測
- styles.css：レイアウト
- assets/：写真はAI生成の写真調イメージと、それに架空の広告面を合成したもの。実在の媒体・広告主ではない。最初の提携成立後、看板会社の許可を得て実在媒体の写真に差し替える

個人情報の取扱いはサイト共通の /privacy.html（京滋ロードサインの利用目的・第三者提供を記載）。計測はサイト共通の /bc-analytics.js（グループ「ロードサイン」）。

## 空き看板の一覧（akiban.html）

**このリポジトリは公開されている。`data/boards.json` も誰でも取得できる。画面で隠しても、JSONに入れた情報は外から読める。**

- 管理は2層に分ける。
  - 非公開の媒体管理台帳（CSV）：看板会社名・担当者・連絡先・正確な所在地・紹介条件・掲載承諾日・承諾者・写真利用許諾・状態・更新履歴。リポジトリの外（Googleドライブなど）か `data/private/`（.gitignore 済み）に置く。列の見本は `tools/boards_ledger_template.csv`。
  - 公開用の `data/boards.json`：台帳から `python3 road-sign/tools/build_boards.py <台帳CSV>` で書き出す。手で編集しない。
- 書き出されるのは、状態が「公開」・掲載承諾日あり・最終確認日が未来でない媒体だけ。`publish_scope` が `full` なら写真・場所・地図・料金まで、`area_price` なら市・種類・料金だけ（場所・向き・写真・地図・許可は出さない）。写真は「写真利用許諾」が「あり」のときだけ出す。
- 成約・撤去・許可の変更があったら、30日を待たずに台帳の状態を「停止」などに変えて書き出し直す。
- `boards.js` も公開してよい項目だけを通し、未来の確認日は「要再確認」と表示する。読み込みに失敗したときは「一覧を読み込めませんでした」と表示し、0面と区別する。
- `min_public` は0（導線を常に表示）。`list_min`（5）は「看板を探す」→「空き看板を探す」に表記を切り替える面数。
- 写真は `assets/boards/` に置き、看板会社の許可を得た実物写真だけを使う。位置情報（Exif）は消してから置く。最終確認日から30日を過ぎると画面上は「要再確認」と表示される。
