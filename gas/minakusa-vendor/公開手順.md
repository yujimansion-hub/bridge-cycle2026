# 南草津駅前 出店者台帳の公開手順

出店者がボタンを押さなくても、次にやることがメールと出店ナビに自動で届くようにする仕組みです。
運営は、スプレッドシートの台帳に「確定エリア・確定日・時間枠」「許可証」「支払」を入れるだけです。
所要時間は10分ほどです。費用はかかりません。

## 最初に1回だけ

1. **info@bridgecycleco.com** でGoogleドライブを開き、新しいスプレッドシートを作って、名前を「南草津駅前 出店者台帳」にします。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初から書いてある `function myFunction() {…}` を全部消し、`Code.gs` の中身を全部貼り付けて保存します。
4. 左の歯車（プロジェクトの設定）で「appsscript.json をエディタに表示」をオンにし、エディタに出た `appsscript.json` の中身を、同じフォルダの `appsscript.json` で置き換えて保存します。タイムゾーンが「(GMT+09:00) 東京」になっていることも確かめます。
5. 上の関数の選択欄で `setup` を選び、「実行」を押します。
   - 「承認が必要です」と出たら info@ を選びます。「Googleで確認されていません」と出たら、「詳細」→「（安全ではないページ）に移動」→「許可」の順に進みます。自分で作ったプログラムなので問題ありません。
   - 「出店者・開催日・当日記録・終了報告・設定・通知記録」のシートができ、自動処理（編集したとき・15分ごと）が入ります。
6. 「デプロイ」→「新しいデプロイ」→ 歯車で「ウェブアプリ」を選び、次のとおりにして「デプロイ」を押します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をClaudeに送ってください。募集ページと出店ナビに設定して公開します。
8. 「設定」シートに、Stripeの支払リンク（3,300円の枠・5,500円の枠）を入れます。どちらも「数量を変更できる」設定にしておくと、日数分まとめて払えます。
9. スプレッドシートのメニュー「出店者台帳」→「自分あてにテスト送信」で、メールが届くか確かめます。

## ふだんの使い方（運営がすること）

| 出店者の段階 | 運営がすること | 自動で起きること |
|---|---|---|
| 申込が来た | 何もしない | 台帳に1行増える。出店者に受付メール（出店ナビの専用リンク入り）、info@ に通知 |
| 区画と日程を決めた | 「確定エリア」（A〜D）「確定日」（2026/12/18。複数日はカンマ区切り）「時間枠」（出店ナビと同じ表示名）を入れる | 3つそろった時点で「区画と日程が決まりました＋許可証の送り方」メール。状態が「区画連絡済」に |
| 許可証が届いた | 「許可証」を「確認済」（写りが悪ければ「不備あり」） | 確認済 →「お支払いのお願い」メール（設定シートの支払リンク入り）。不備あり →「もう一度送ってください」メール |
| 支払を確認した | 「支払」を「済」 | 「出店が確定しました」メール（搬入口（仮）と当日の流れ）。状態が「出店確定」に |
| 前日 | 何もしない | 前日18時に「明日は出店日です」メール（時刻は設定シートで変更可） |
| 開催・中止を決めた | 「開催日」シートの「開催判断」を「開催」または「中止」に（理由は右の欄へ） | その日の確定済みの出店者全員にメール。中止の日は当日のお知らせを止める |
| 当日 | 何もしない | 開店90分前に「まもなく設営開始」メール。閉店時刻に「片付けの写真と終了報告を」メール。閉店3時間後に報告がまだなら1回だけ催促 |
| 写真・終了報告が届いた | 何もしない | 「当日記録」「終了報告」シートに記録し、info@ にも写真付きで届く。出店者にお礼メール |
| 見送るとき | 「状態」を「見送り」 | 丁寧なお断りメール |

- 出店ナビは1分ごとに台帳を見て、出店者の「次にやること」を自動で切り替えます。出店者がボタンを押す必要はありません。
- メニュー「出店者台帳」→「いまの状況を見る」で、状態ごとの件数と売上・人数の合計が出ます。
- 自動メールを一時的に止めたいときは、「設定」の「自動通知」を「オフ」にします。

## 知っておくこと

- **送信の上限**：Google Workspace は1日1,500通。19店×9日でも上限には届きません。
- **プログラムを直したとき**：「デプロイ」→「デプロイを管理」→ 鉛筆 →「新バージョン」→「デプロイ」。「新しいデプロイ」を押すとURLが変わり、ページとつながらなくなります。
- **台帳が止まったとき**：募集ページはこれまでの受付（フォームの中継）に自動で切り替わり、出店ナビは出店者がボタンで進める方式に戻ります。
- **個人情報**：「出店者」シートにはメールと電話番号が入ります。共有は必要な人だけに。出店ナビの専用リンク（`?t=…`）は出店者ごとの鍵なので、ほかの人に知らせないでください。
