# 南草津駅前、よりみち。 台帳の公開手順

> 2026-10-19 公開済み。台帳は info@bridgecycleco.com のGoogleドライブ「南草津よりみち 台帳」。ページの API に公開URLを設定済み。
> 権限は appsscript.json の oauthScopes で固定している（許可画面で一部だけ選ばれて止まるのを防ぐため）。プロジェクト設定で「appsscript.json をエディタに表示」をオンにして編集する。

ページ（minakusa-yorimichi.html）からの投票と開催案内の登録を、Googleスプレッドシートに集めます。開催案内メールと前日のお知らせメールも、このスプレッドシートから送ります。
所要時間は10分ほどです。費用はかかりません。

## 最初に1回だけ

1. **メールの送信元にしたいGoogleアカウント**でGoogleドライブを開きます。新しいスプレッドシートを作り、名前を「南草津よりみち 台帳」にします。
   - 登録者へのメールは、このアカウントのアドレスから届きます。返信先は info@bridgecycleco.com に設定してあります。
2. メニューの「拡張機能」→「Apps Script」を開きます。
3. 最初から書いてある `function myFunction() {…}` を全部消し、`Code.gs` の中身を全部貼り付けて保存します。
4. 左の歯車（プロジェクトの設定）で、タイムゾーンを「(GMT+09:00) 東京」にします。
5. 上の関数の選択欄で `setup` を選び、「実行」を押します。
   - 「承認が必要です」と出たら、自分のアカウントを選びます。「Googleで確認されていません」と出たら、「詳細」→「（安全ではないページ）に移動」→「許可」の順に進みます。自分で作ったプログラムなので問題ありません。
   - スプレッドシートに「設定・投票・登録・並ぶもの・送信記録」の5つのシートができます。
6. 右上の「デプロイ」→「新しいデプロイ」を押します。歯車で種類に「ウェブアプリ」を選び、次のとおり設定して「デプロイ」を押します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
7. 表示された「ウェブアプリのURL」（`https://script.google.com/macros/s/…/exec`）をコピーします。
   - 「設定」シートの「受付のURL」の欄に貼ります。メールの配信停止リンクに使います。
   - 同じURLをClaudeに送ってください。ページに設定して公開します。
8. スプレッドシートを開き直すと、メニューに「よりみち」が出ます。「自分あてにテスト送信」で、3通（登録確認・開催案内・前日のお知らせ）が届くか確かめます。

## ふだんの使い方

| したいこと | すること |
|---|---|
| 次の情報更新日を変える | 「設定」の「次の情報更新」を書き換える（2分以内にページへ反映） |
| お店の商品を載せる | 「並ぶもの」に1行入れて「公開する」にチェック。写真はClaudeに送れば、ページ用に置いて場所を入れます |
| 開催日を発表する | 「設定」の開催日・開催日の表示・時間・場所・店数を入れる → ページが開催案内に切り替わる → 「自分あてにテスト送信」で文面を確認 → 「開催案内を送る」 |
| 先行案内を送る | 開催日を入れたら、まずメニュー「先行案内を送る」。会員番号100まで（「設定」の先行案内の人数）に先に届く。翌日以降に「開催案内を送る」で残りの人へ |
| SNSの自動下書きを始める | 「設定」の「SNS自動下書き」を「オン」にする。毎週火・金の朝に、定期の作業がMetricoolへ「承認待ち」の投稿を入れる（承認するまで公開されない） |
| 前日のお知らせ | 何もしなくてよい。毎日12時に確認し、翌日が開催日なら自動で送る |
| 次の回に進む | 「開催の回」を「第2回」にし、開催日などを書き換える。送った印は回ごとなので、全員にまた届く |
| いまの集計を見る | メニュー「よりみち」→「いまの集計を見る」。有効回答（版がv2のもの）だけを数え、時間・出口は未回答を除いた割合 |
| 配信を止めたい人がいる | メール末尾のリンクで本人が止められる。手で止めるときは「登録」の状態を「停止」にする |

## 知っておくこと

- **送信の上限**：通常のGmailは1日100通、Google Workspaceは1日1,500通です。上限を超えた分は「送信記録」に残り数が出るので、翌日もう一度「開催案内を送る」を押してください。前日のお知らせは上限を超えると送れないため、登録が90人を超えたらWorkspaceのアカウントに移すことを勧めます。
- **プログラムを直したとき**：「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」→「デプロイ」の順に更新します。「新しいデプロイ」を押すとURLが変わり、ページとつながらなくなります。
- **台帳が止まったとき**：ページは自動で、これまでの受付先（Formspree）に送ります。表示は、ページに書いてある設定に戻ります。
- **個人情報**：「登録」シートにはメールアドレスが入ります。スプレッドシートの共有は、必要な人だけにしてください。
- **これまでの回答**：Formspreeに届いた分は、Formspreeの管理画面からCSVで書き出してClaudeに送ってください。「投票」「登録」シートに貼れる形に整えます。版がv2より前の投票は、今までどおり集計から外れます。
